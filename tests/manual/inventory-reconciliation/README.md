# 本地庫存核對

從倉庫根目錄用一個入口啟動案例。

```sh
sh tests/manual/inventory-reconciliation/session.sh start
```

請讓參與者只讀啟動輸出、當輪提供的參與者檔案，以及分階段回傳的文字。保留 `INSTANCE`，按提示保存實際提交的整份 `report.json` 和 `judgment.md`，再用同一腳本執行 `first INSTANCE`。首輪全對即結束；首輪有誤會先封存原稿，再顯示提示。修正版另存後用 `finish INSTANCE` 結束。

判分核對兩個商品、完整報表結構及庫存整數，每個商品只允許一筆。案例的 `result.json` 記錄首次正確（`unprompted_correct`）、提示後正確（`hinted_correct`）或提示後仍錯（`still_incorrect`）。文字判斷以原檔封存，供人工核對依據。缺件時保留收到的檔案，尚未判分。

所有關鍵原始記錄首輪都已提供。提示指向既有記錄的欄位。結果顯示這次提交與固定預期是否一致，兩輪差異不足以歸因。操作者若透過聊天發放提示，保留實際投遞和回覆。操作者檔案與判分程式可被同一使用者讀取，參與者應避免開啟。製作案例或已讀預期的人所跑的流程只作工程自檢。
