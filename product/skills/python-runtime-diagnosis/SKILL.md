# Python 運行時阻斷歸因

把一次失敗歸到正確的控制層，再決定寫入工作簿的事實、假設與問題。本 Skill 只做歸因，不提供繞過方法；需要的下一步超出授權時，停止該操作。

## 三個問題

1. **失敗來自哪個操作、哪一層？** 候選層：Python 審計 hook、作業系統存取控制、宿主或用戶授權、程式本身錯誤。依據例外類型與拋出位置、errno、宿主拒絕記錄分辨；分不出來就保留多個解釋。
2. **該層機制的作用範圍與版本是否已知？** 解釋器實作與版本、hook 註冊層、部署設定。未知時寫 unknown，不以文檔版本代替目標版本。
3. **結論有沒有超出觀察？** 對照 `references/runtime-boundaries.md` 的「不能外推」表。

## 交回

- facts：只寫觀察到的操作、層與原始錯誤。
- hypotheses：至少一個替代解釋。
- questions：能區分解釋的最小缺失證據。
- 下一步限於現有授權；授權外的操作寫成停止理由，技術上可行不代替授權。

需要機制細節時，只讀 `references/runtime-boundaries.md` 的對應小節。
